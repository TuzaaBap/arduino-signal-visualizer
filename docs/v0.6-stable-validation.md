# Arduino Signal Visualizer v0.6.0 stable validation

Date: 2026-08-12

## Result

Arduino Signal Visualizer v0.6.0 is release-qualified for the Arduino Uno R3
scope described in this document. The final application/library pair passed
physical GPIO, ADC, PWM, transparent Serial, reconnect, packet-integrity,
bounded-buffer, memory, packaging, and beginner-sketch checks.

I2C and SPI instrumentation are not part of this release. Ordinary Arduino
`Wire` and `SPI` use remains available and is covered by a coexistence compile
regression.

## Release-blocking defect found and corrected

The first high-rate run reproduced the earlier intermittent transport failure
after approximately five minutes: a four-packet sequence gap followed by two
out-of-order packets and one duplicate. CRC remained zero, identifying UART/
USB scheduling at near-wire-capacity traffic as the likely cause rather than a
damaged frame.

The firmware scheduler now measures the sketch-selected UART baud and limits
ASV telemetry to two thirds of its 8N1 wire capacity. The remaining third is
reserved for normal sketch Serial traffic and USB-bridge timing margin. This
does not add a growing queue or block the sketch: the existing bounded slots
retain the newest pending state for every signal.

The instrumented high-rate sketch uses 5,628 bytes of flash (17%) and 340 bytes
of SRAM (16%), leaving 1,708 bytes for local variables.

## Stable release limitations

- The supported hardware is the Arduino Uno R3/ATmega328P.
- I2C and SPI instrumentation are deliberately excluded pending representative
  peripheral-hardware validation. Uno bus pin labels are factual board labels,
  not a claim that bus traffic is decoded.
- PWM is reconstructed from captured timer configuration; ADC voltage is
  calculated from declared reference metadata. ASV is not an oscilloscope,
  electrical probe, or asynchronous logic analyzer.
- Normal text Serial is supported. Arbitrary binary user data that exactly
  imitates a complete, valid ASV frame cannot be transparently distinguished
  on the Uno's single UART without an opt-in strict framing mode.
- Updater packages are cryptographically signed, but Windows installers lack a
  commercial Authenticode identity and macOS bundles are not Apple-notarized.
  SmartScreen or Gatekeeper may therefore request confirmation.
- Windows installation and physical Uno behavior were tested locally. macOS
  packages are built natively and audited by GitHub Actions, but were not
  physically opened on Apple hardware during this validation session.
- v0.6.0 is the first updater-enabled stable base. A real update from v0.6.0 to
  a newer signed stable version can only be completed when that newer version
  exists; this remains the v0.6.1 release gate.

These limitations are stated in the README and release notes so the stable
label describes a dependable supported scope rather than unrestricted hardware
or measurement claims.
